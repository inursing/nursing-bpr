📖 取得金鑰的簡易教學

課堂上老師會用 QR Code 幫大家設定好，不用做這些。課後想自己練習時，只要有一把 Gemini 金鑰就可以（免費、不需信用卡）；病人聲音會用手機／電腦內建的語音。

步驟一：申請 Gemini 金鑰（約 2 分鐘）

  1. 用 Google 帳號登入 aistudio.google.com/apikey
  2. 第一次進入會請你同意條款，勾選後按「繼續」。
  3. 按右上角 「Create API key」（建立 API 金鑰）。若問要選哪個 project，選預設的或按「Create project」隨便取個名字即可。
  4. 出現一串以 AIza 開頭的金鑰，按旁邊的複製鈕。
    這串金鑰等於你的密碼，不要貼到群組或公開的地方。

步驟二：貼到練習平台

  1. 打開練習平台 → 右上角 ⚙ 設定。
  2. 展開 「④ 學生課後練習：使用自己的金鑰」。
  3. 勾選「使用我自己的金鑰」，把金鑰貼到「我的 Gemini API 金鑰」。
  4. 按 儲存。之後選個案、開始會談即可。

回到課堂要用老師的設定時，把「使用我自己的金鑰」取消勾選就好，老師的設定仍然保留。

常見問題

免費額度夠嗎？ 免費層每天可以練習很多次；一次 10 分鐘的會談加 AI 報告大約用掉 15–25 次請求。若出現「限流／429」，等幾分鐘再試。

可以讓病人的聲音更自然嗎？ 可以，但要另外申請 Azure 語音服務（需 Microsoft 帳號並綁信用卡，有免費額度）。一般課後練習用內建語音就足夠；需要的話在「⑤ 進階」填入 Azure 金鑰與區域。

金鑰會傳到哪裡？ 只存在你這台裝置的瀏覽器裡，平台不會上傳到任何伺服器；清除瀏覽器資料就會消失。
